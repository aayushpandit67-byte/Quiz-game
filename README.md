# Quiz Game 

A simple and interactive Quiz Game built using **HTML**, **CSS**, and **JavaScript**. This project allows users to answer multiple-choice questions,
receive instant feedback, and navigate through questions using a clean and modern user interface.

##  Features

* Modern glassmorphism-inspired user interface
* Multiple-choice quiz questions
* Instant answer validation
* Visual feedback for correct answers
* Next button for seamless question navigation
* Responsive and user-friendly design
* Clean and attractive layout
* Dynamic quiz functionality powered by JavaScript
* Built with pure HTML, CSS, and JavaScript
* Score tracking system 

## Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and layout
* **JavaScript (ES6)** – Quiz logic and interactivity

## How It Works

1. The quiz loads a question and its answer options.
2. The user selects an answer.
3. The selected answer is validated.
4. Correct answers are highlighted.
5. The **Next** button appears after answering.
6. The user proceeds through all questions until the quiz ends.
7. Final score is displayed.
